# Resilience-Engine Pro
Automated financial risk assessment tool that processes data in real-time.

## Features
- Automated multi-company risk assesment.
- Visual dasboard with Rd/Green risk signaling.
- Bult using Python, Steamlit and Pandas.

 ## How to run
1. Install requirements: 'pip install streamlit pandas openpyxl'
2. Run app: 'streamlit run main.py'
